# 04: Painel flutuante de propriedades

**What to build:** Clicar num Nó abre o formulário daquele tipo num painel que flutua sobre o canvas, com botão de fechar. Cada tipo de Nó traz seus próprios campos. O painel é o mesmo do seletor de nós: abrir um fecha o outro, de forma que nunca haja dois competindo pelo mesmo espaço.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Painel flutuante com sombra, à direita, com botão de fechar
- [ ] Seletor de nós e propriedades são o mesmo painel em dois modos exclusivos
- [ ] Cada tipo de Nó tem seu formulário, incluindo gatilho com escolha de Canal
- [ ] Configuração longa, como o corpo de uma Requisição HTTP, abre em janela cheia
- [ ] Editar propriedade salva no rascunho
- [ ] Fechar o painel deixa o canvas completamente limpo
